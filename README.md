# FileExplorer — 멀티 분할 경량 파일 탐색기

Windows 11 이상(x64)에서 하나의 창을 **자유 분할(트리형)**하고, 각 패널이 **독립 탭**을 가지며, 좌측 **워크스페이스 목록**으로 여러 벌의 탐색기 화면을 전환하는 초경량 파일 탐색기입니다. UI는 Rust의 egui(eframe/glow)로 직접 그리고, 아이콘·컨텍스트 메뉴·변경 감시·파일 실행 같은 셸 연동은 windows-rs로 Win32 API를 호출합니다 (Q-Dir의 멀티 패널 + VS Code의 자유 분할 UX 참고).

## 핵심 기능

- **워크스페이스**: 좌측 사이드바에서 워크스페이스를 만들면(`+` 버튼·워크스페이스 메뉴) 그 워크스페이스만의 탐색기 화면이 생기고, 항목을 고르면 즉시 전환됩니다. 워크스페이스마다 분할 구성·패널·탭·히스토리가 완전히 독립이며, 항목은 이름과 현재 폴더 경로를 2줄로 보여줍니다. 이름 바꾸기(`F2`·우클릭), 삭제(확인 후 — 마지막 1개는 불가), 드래그로 순서 변경을 지원합니다
- **사이드바 조절**: 경계선 드래그로 폭 변경(160~480px), `Ctrl+B`·보기 메뉴·사이드바 상단 `◧` 버튼으로 접기/펼치기 (접힌 상태·폭도 저장됩니다)
- **자유 분할**: 패널을 **네 방향 중 원하는 쪽으로** 중첩 분할합니다 — 새 패널이 오른쪽·왼쪽·위쪽·아래쪽 어디에 놓일지 고를 수 있습니다. 진입점은 **각 패널 탭 스트립 오른쪽 끝의 분할 버튼**(누르면 네 방향 메뉴 — 그 패널이 대상)과 보기 메뉴이며, 단축키는 `Ctrl+Alt+←/→/↑/↓`입니다. 기존 `Ctrl+\`(오른쪽)·`Ctrl+Shift+\`(아래쪽)도 그대로 동작합니다. 스플리터 드래그로 비율 조절, `Ctrl+Shift+W` 패널 닫기 (마지막 1개는 닫기 불가)
- **패널별 탭**: `Ctrl+T` 새 탭(현재 경로 복제), `Ctrl+W` 탭 닫기(마지막 탭은 패널 닫기로 연결), 탭 클릭 전환, 탭별 독립 히스토리. 탭이 많으면 탭 영역만 가로로 스크롤되고 분할 버튼은 오른쪽 끝에 남습니다
- **파일 목록**: 상세 보기(이름·크기·종류·수정한 날짜), 열 클릭 정렬(탐색기와 동일한 숫자 인지 정렬·폴더 우선), 시스템 아이콘, 보이는 행만 그리는 가상 스크롤 + 백그라운드 열거(대량 폴더 UI 무정지)
- **탐색**: 주소창 경로 입력(Enter), 뒤로/앞으로/상위(`Alt+←/→/↑`), 더블클릭 폴더 진입·파일 실행, 잘못된 경로 입력 시 현 위치 유지
- **폴더 트리**: 패널별 토글(보기 > 폴더 트리, 패널 상태 줄의 `폴더 트리` 버튼) — 드라이브 루트에서 지연 확장(하위 1단계만 워커 열거), 노드 클릭 시 활성 탭 이동 (단방향)
- **셸 컨텍스트 메뉴**: 우클릭(다중 선택 지원)으로 Windows 표준 메뉴 — 복사·삭제·속성·보내기 등 파일 작업 전부 셸 위임, 빈 영역 우클릭은 폴더 배경 메뉴(새로 만들기 — 목록이 화면을 다 채우지 않을 때)
- **변경 자동 새로고침**: 표시 중 폴더를 감시(ReadDirectoryChangesW)해 외부 변경 시 300ms 디바운스 후 자동 갱신, `F5` 수동 새로 고침
- **세션 저장/복원**: 종료 시 워크스페이스 목록·각 워크스페이스의 분할 구성과 탭 경로·사이드바 폭/접힘·창 위치/최대화를 `%APPDATA%\FileExplorer\settings.json`에 저장, 재시작 시 복원. 재시작 직후에는 **활성 워크스페이스의 탐색기만 생성**하고 나머지는 선택할 때 만듭니다(메모리 절약). 손상·구버전 파일은 기본 레이아웃으로 폴백합니다
- **다크 테마**: 창 전체(타이틀바·메뉴바·파일 목록·폴더 트리·주소창·탭·워크스페이스 사이드바)를 고정 다크 스타일로 표시합니다(전환 UI 없음). 메뉴 팝업도 앱 팔레트를 따릅니다
- 긴 경로(260자+)·유니코드 파일명, Per-Monitor v2 DPI, 한국어 UI

**성능 실측 (release, 2026-07-28)**: 시작→창 표시 중앙값 133ms(2회차 이후) · 1워크스페이스·2패널 유휴 메모리 137.6MB · 워크스페이스 5개 방문 124.1MB · 10만 파일 폴더 진입 후 143.8MB, 목록 렌더 p95 0.63ms — PRD NFR-1·2(150MB)·3·8(200MB) 충족

## 실행 방법

```
cargo run              # 디버그 실행
cargo build --release  # 배포 빌드 (단일 exe, 약 4.6MB)
```

요구 사항: Rust stable(1.80+, msvc 툴체인), Windows 11 이상.

검증: `cargo test`(단위테스트), `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`

## 아키텍처

계층형 단일 crate — 모듈 분리 (상세 규약은 `AGENTS.md`, 요구사항 정본은 `docs/prd.md`):

```
src/
├── main.rs            # 진입점 — COM 초기화, 세션 로드, egui 창 실행
├── lib.rs             # 라이브러리 타깃 — 통합 테스트(tests/)용 모듈 재수출
├── ui/                # egui UI 계층 — 화면 구성·입력 처리 전부
│   ├── app.rs         # 앱 골격 — 워크스페이스 목록·뷰 소유, 세션 반영/수집, 창 상태 추적
│   ├── sidebar.rs     # 워크스페이스 사이드바 (2줄 카드·인라인 편집·드래그 정렬)
│   ├── splitter.rs    # 분할 트리를 화면에 배치하고 스플리터를 드래그
│   ├── panel.rs       # 패널 — 탭 스트립/주소창/트리/목록 조립, pending-커밋 탐색, 변경 감시
│   ├── tree.rs        # 폴더 트리 — 드라이브 루트 + 지연 확장(워커 열거)
│   ├── file_list.rs   # 파일 목록 — 가상 스크롤·열 정렬·다중 선택·지연 아이콘
│   ├── tabs.rs        # 탭 스트립 + 오른쪽 끝 분할 버튼(네 방향 팝업)
│   ├── address_bar.rs # 주소창·히스토리 버튼
│   ├── menu.rs        # 메뉴 바·단축키 테이블
│   ├── session.rs     # 앱 상태 ↔ 세션 파일 변환 (순수)
│   ├── icon_tex.rs    # 시스템 아이콘 → egui 텍스처 변환
│   ├── shell_host.rs  # 셸 컨텍스트 메뉴용 HWND 확보·서브클래스
│   └── theme.rs       # 고정 다크 팔레트
├── app/               # 순수 로직 (UI 프레임워크 비의존)
│   ├── workspace.rs   # 워크스페이스 목록 모델 (추가/이름/삭제/정렬/부제)
│   ├── layout.rs      # 분할 레이아웃 트리 (split/close/비율/배치/스냅숏)
│   ├── settings.rs    # 세션 직렬화 v2 (serde)
│   └── theme.rs       # 프로세스 전역 다크 정책 (제목 표시줄)
├── panel/             # 순수 모델
│   ├── tabs.rs        # 탭 모델
│   ├── file_list.rs   # 정렬 비교·크기/날짜 표시 규칙
│   └── history.rs     # 탭별 탐색 히스토리
├── fs/
│   ├── enumerate.rs   # 워커 스레드 디렉터리 열거 (FindFirstFileExW, \\?\ 긴경로)
│   ├── icons.rs       # 셸 아이콘·종류 캐시 (시스템 이미지 리스트 공유)
│   ├── shell_menu.rs  # IContextMenu 셸 컨텍스트 메뉴 (COM — unsafe 격리)
│   └── watcher.rs     # 폴더 변경 감시 (ReadDirectoryChangesW + 디바운스)
└── tests/
    ├── layout_flow.rs # 분할·닫기 시퀀스 통합 테스트
    └── watcher.rs     # 감시 통합 테스트 (채널 검증)
```

> `app/{window,sidebar,menu,layout_host}.rs`·`panel/{panel,folder_tree,address_bar}.rs`와
> `panel/{file_list,tabs}.rs`의 Win32 컨트롤 래퍼는 **이식 이전 구현**으로 소스에 남아 있지만
> 실행 파일에는 쓰이지 않습니다.


핵심 플로우: 탐색 요청 → `PanelState::navigate`(pending 등록, 세대 번호 증가) → 워커 스레드 열거 → 채널 수신 후 프레임에서 반영 → **성공 시에만** 경로·히스토리 커밋(실패하면 현 위치·목록 유지) → 커밋된 폴더로 변경 감시 교체. 파일 작업(복사·삭제 등)은 셸 컨텍스트 메뉴에 위임하며, 이 메뉴는 자체 메시지 루프를 돌리므로 프레임 그리기가 모두 끝난 뒤에 띄웁니다. 종료 시 세션 수집·저장, 시작 시 복원.

워크스페이스 플로우: 사이드바 클릭 → 그 워크스페이스가 활성이 되고, **처음 선택이면** 저장된 구성으로 분할·탭을 만듭니다(지연 생성 — 방문하지 않은 워크스페이스는 패널도 열거 스레드도 없습니다). 이미 만든 워크스페이스는 상태를 그대로 갖고 있어 스크롤·선택이 유지됩니다. 활성 패널의 폴더가 바뀌면 사이드바 카드의 둘째 줄이 따라 갱신됩니다.
