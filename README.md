# MOA — 멀티 분할 경량 파일 탐색기

Windows 11 이상(x64)에서 하나의 창을 **자유 분할(트리형)**하고, 각 패널이 **독립 탭**을 가지며, 좌측 **워크스페이스 목록**으로 여러 벌의 탐색기 화면을 전환하는 초경량 파일 탐색기입니다. UI는 Rust의 egui(eframe/glow)로 직접 그리고, 아이콘·컨텍스트 메뉴·변경 감시·파일 실행 같은 셸 연동은 windows-rs로 Win32 API를 호출합니다 (Q-Dir의 멀티 패널 + VS Code의 자유 분할 UX 참고). **FTP·FTPS·SFTP 원격 서버**를 로컬 폴더와 같은 패널·탭에서 다룹니다.

## 핵심 기능

- **워크스페이스**: 좌측 사이드바에서 워크스페이스를 만들면(`+` 버튼) 그 워크스페이스만의 탐색기 화면이 생기고, 항목을 고르면 즉시 전환됩니다. 워크스페이스마다 분할 구성·패널·탭·히스토리가 완전히 독립이며, 항목은 이름과 현재 폴더 경로를 2줄로 보여줍니다. 이름 바꾸기(`F2`·우클릭), 삭제(확인 후 — 마지막 1개는 불가), 드래그로 순서 변경을 지원합니다
- **사이드바 조절**: 경계선 드래그로 폭 변경(160~480px), `Ctrl+B`·**타이틀바 왼쪽 버튼**으로 접기/펼치기 (접힌 상태·폭도 저장됩니다)
- **커스텀 타이틀바**: 창 제목 표시줄을 앱이 직접 그립니다 — 왼쪽에 앱 아이콘과 워크스페이스 목록 표시 토글, 가운데에 활성 워크스페이스 이름, 오른쪽에 설정 메뉴와 최소화·최대화·닫기 버튼. 앱 아이콘은 `docs/AppIcon.ico` 한 장으로 타이틀바·작업 표시줄·실행 파일이 모두 같은 그림을 씁니다. 타이틀바 빈 영역을 끌어 창을 옮기고(화면 가장자리 스냅 지원), 더블클릭으로 최대화/복원하며, 창 가장자리·모서리를 끌어 크기를 바꿉니다. 설정 메뉴(⚙)에는 `설정 · 업데이트 · 릴리즈 노트 · 오픈소스 라이선스 · 정보`가 있고 **`설정`이 아래의 설정 화면을, `오픈소스 라이선스`가 라이선스 고지 화면을, `정보`가 앱 정보 화면을 엽니다**(나머지 둘은 아직 준비 중이라 비활성). OS 장식을 끈 대신 창 그림자·둥근 모서리와 Windows 11 스냅 레이아웃 팝업(최대화 버튼 호버 메뉴)은 없습니다. 최대화·복원·최소화는 OS 전환 애니메이션 없이 곧바로 바뀝니다 — 그 애니메이션이 바뀌기 전 화면과 새 화면을 겹쳐 페이드해 글자가 이중으로 보였기 때문입니다
- **설정 화면**: 타이틀바 설정 메뉴(⚙)의 `설정`으로 여는 대화이며, 다섯 묶음이 한 화면에 있습니다(항목이 창보다 길면 본문만 스크롤되고 제목·`닫기`는 제자리에 남습니다). **바꾸는 즉시 반영되고 저장됩니다**(확인 버튼 없음).
  - `모양` — **글꼴**: PC에 깔린 글꼴 중 **한글을 실제로 그리는 것만** 골라 목록에 냅니다(목록은 앱이 시작할 때 백그라운드에서 미리 읽어 둡니다 — 대화를 열면 대개 곧바로 나옵니다). 고르면 곧바로 앱 전체 글꼴이 바뀌고, `기본값 (맑은 고딕)`으로 되돌릴 수 있습니다
  - `시작` — **윈도우 시작 시 실행**: 켜면 `HKCU\…\Run`에 등록합니다(관리자 권한 불필요). 트레이 토글이 함께 켜져 있으면 부팅 시 **창 없이 트레이로만** 올라옵니다
  - `종료` — **닫으면 트레이로 보내기**: 켜면 ① 트레이 아이콘이 창이 떠 있는 동안에도 보이고 ② 닫기(`✕`)가 종료 대신 창을 숨기며 ③ 아이콘 더블클릭이 창을 다시 최상위로 띄우고 ④ 아이콘 우클릭에 `열기`·`종료` 메뉴가 붙습니다. 창을 숨길 때도 세션을 저장합니다
  - `언어` — **앱 언어**: `시스템 기본`·`한국어`·`English` 중에서 고르면 **다음 프레임부터** 모든 화면 문구가 바뀝니다(재시작 불필요). `시스템 기본`은 Windows 사용자 UI 언어가 한국어면 한국어, 아니면 영어입니다. 드롭다운 항목 이름도 지금 언어를 따릅니다. **다만 이미 떠 있는 실패 사유**(연결·전송)는 실패한 순간의 언어로 남고 다음 실패 때 새 언어로 나옵니다
  - `파일 보기` — 토글 셋입니다. **파일 확장명 표시**(끄면 목록에서 이름 뒤 확장자를 뗍니다 — 폴더·`..`·확장자 없는 파일은 그대로) · **숨김 파일 및 폴더 표시**(끄면 숨김 속성이 붙은 로컬 항목과 이름이 `.`으로 시작하는 원격 항목이 빠집니다) · **시스템 파일 표시**(끄면 시스템 속성이 붙은 로컬 항목이 빠집니다. **기본값이 꺼짐**이라 `pagefile.sys`·`System Volume Information` 같은 항목은 켜야 보입니다). 뒤의 둘은 **속성마다 제 토글을 봅니다** — 두 속성이 함께 붙은 항목은 두 토글이 모두 켜져야 보이며, 이는 탐색기의 `숨김 파일 표시`와 `보호된 운영 체제 파일 숨기기` 조합과 같은 규칙입니다. 걸러진 뒤의 개수가 폴더·파일 개수 표시의 기준이 되고, **폴더 트리에도 같이** 적용되며 바꾸면 트리가 하위 목록을 다시 읽습니다. 켜서 보이는 숨김·시스템 항목은 **아이콘과 글자를 함께 흐리게**(불투명도 절반) 그려 보통 항목과 구분합니다 — 탐색기와 같은 표시이며 **보기 모드 8종 모두**에 적용됩니다(폴더 트리는 그대로입니다). 셋 다 **로컬·원격 목록에 같이** 적용되지만 원격 서버에는 시스템 속성이 없어 그 토글은 원격 목록을 바꾸지 않습니다. 정렬·선택·경로 조립·파일 실행은 언제나 **원래 이름**을 씁니다
- **오픈소스 라이선스 고지**: 타이틀바 설정 메뉴(⚙)의 `오픈소스 라이선스`로 여는 대화입니다. 왼쪽에 이 앱이 쓰는 구성 요소 목록(이름·버전), 오른쪽에 고른 것의 SPDX 식별자·저작권자·**라이선스 전문**이 보입니다. `MIT OR Apache-2.0`처럼 선택형으로 선언된 것은 전문을 둘 다 싣고, 배포 패키지에 원문이 없는 것은 그 라이선스의 표준 전문을 대신 보이며 그 사유를 함께 적습니다. 크레이트가 아닌 것도 담습니다 — 정적 링크되는 **libssh2**·**zlib**과 실행 파일에 담기는 **Phosphor 글꼴**. 고지 자료는 실행 파일에 함께 들어 있어 네트워크 없이도 보이며, `cargo run --example gen_licenses`로 다시 만듭니다(의존성을 바꾸고 다시 만들지 않으면 `cargo test`가 실패합니다)
- **앱 정보**: 타이틀바 설정 메뉴(⚙)의 `정보`로 여는 작은 팝업입니다. 가운데에 앱 아이콘(96px), 그 아래에 이름과 버전이 `MOA 0.1.0` 한 줄로 서고 `닫기` 버튼 하나가 있습니다. 버전은 `Cargo.toml`에서 빌드 시점에 박히므로 따로 손댈 곳이 없습니다. 아이콘은 **화면 배율에 맞는 물리 픽셀 크기로 미리 줄여** 그립니다 — 큰 그림을 그대로 올려 GPU가 줄이면 가장자리가 자글거리기 때문이며, 원본 자산은 `cargo run --example gen_app_icon`으로 다시 만듭니다
- **중복 실행 방지**: 이미 떠 있으면(창이 보이든 트레이에 숨어 있든) 새로 실행한 프로세스는 창을 만들지 않고 **기존 창을 최상위로 띄운 뒤 스스로 끝납니다** — 두 프로세스가 같은 설정 파일에 서로 덮어써 세션이 깨지는 것을 막습니다
- **자유 분할**: 패널을 **네 방향 중 원하는 쪽으로** 중첩 분할합니다 — 새 패널이 오른쪽·왼쪽·위쪽·아래쪽 어디에 놓일지 고를 수 있습니다. 진입점은 **각 패널 탭 스트립 오른쪽 끝의 패널 메뉴**(그 패널이 대상)이며, 단축키는 `Ctrl+Alt+←/→/↑/↓`입니다. 기존 `Ctrl+\`(오른쪽)·`Ctrl+Shift+\`(아래쪽)도 그대로 동작합니다. 스플리터 드래그로 비율 조절, `Ctrl+Shift+W` 패널 닫기 (마지막 1개는 닫기 불가). 분할하면 **패널마다 테두리**가 그려져 경계가 드러나고, 지금 조작 중인 패널은 더 밝은 테두리로 구분됩니다. 새 패널은 나뉜 패널과 같은 폴더에서 시작하며, 그 패널이 **원격 탭을 보고 있었으면 시작 폴더**에서 시작합니다
- **패널 메뉴**: 탭 스트립 오른쪽 끝 버튼을 누르면 그 패널을 대상으로 하는 메뉴가 열립니다 — `보기`(마우스를 올리면 보기 모드 8종이 펼쳐짐) · 네 방향 분할 · `새로 고침`(F5) · `새 파일`·`새 폴더` · `닫기`(Ctrl+Shift+W, 마지막 패널은 비활성). **상단 메뉴 바는 없습니다** — 항목이 모두 이 메뉴와 주소창·탭 스트립·사이드바에 있습니다
- **패널별 탭**: `Ctrl+T` 새 탭(현재 경로 복제 — **원격 탭에서는 시작 폴더를 여는 로컬 탭**), `Ctrl+W` 탭 닫기(마지막 탭은 패널 닫기로 연결), 탭 클릭 전환, 탭별 독립 히스토리. 탭 하나에 **폴더 아이콘·이름·닫기(×)**가 함께 들어 있고(가운데 버튼 클릭으로도 닫힙니다), 활성 탭만 배경으로 강조됩니다. 탭이 많으면 탭 영역만 가로로 스크롤되고 분할 버튼은 오른쪽 끝에 남습니다
- **보기 모드 8종**: `아주 큰 아이콘`(256px) · `큰 아이콘`(96px) · `보통 아이콘`(48px) · `작은 아이콘`(16px) · `목록` · `자세히` · `타일` · `내용`. 패널 메뉴의 `보기`에 마우스를 올리면 펼쳐지고 현재 모드에 점이 붙습니다. **작은 아이콘은 왼→오른쪽, 목록은 위→아래로** 채워 서로 다르게 흐릅니다. 모드는 패널마다 독립이며 세션에 저장됩니다
- **썸네일 미리보기**: 아이콘 4종·타일·내용 보기에서 사진·동영상·문서의 **실제 미리보기**를 보입니다(`IShellItemImageFactory`). 워커 스레드가 만들고 준비 전에는 형식 아이콘을 보여주며, 패널당 최근 200장(약 50MB)만 들고 폴더를 떠나면 즉시 놓습니다. 자세히·목록 보기는 16px 형식 아이콘을 유지합니다
- **파일 목록**: 자세히 보기는 이름·크기·종류·수정한 날짜 4열이며 **열 경계를 끌어 폭을 조절**할 수 있습니다(패널마다 독립·세션 저장). 머리글의 열 경계마다 **세로 구분선**이 서 있어 어디를 잡을지 보이고, 끄는 동안에는 그 경계가 목록 바닥까지 강조색으로 이어집니다. 열 폭 합이 패널보다 넓으면 가로로 스크롤되고, 폭을 넘는 글자는 모든 열에서 `…`로 줄여 한 줄로 보입니다. **크기는 소수점 둘째자리까지 KB·MB·GB로** 보입니다(`1.00 KB`·`1.18 MB` — 폴더는 빈 칸). 열 클릭 정렬(탐색기와 동일한 숫자 인지 정렬·폴더 우선), 시스템 아이콘, 보이는 것만 그리는 가상 스크롤 + 백그라운드 열거(대량 폴더 UI 무정지). **다 읽었는데 항목이 하나도 없으면 `이 폴더는 비어 있습니다`**가 목록 자리에 서고(끌어다 놓기는 그대로 받습니다), **아직 아무것도 읽지 못한 채 읽는 중일 때는 목록 자리에 자리표시 8줄**이 서고 목록 위에 `읽는 중…`이 붙습니다 — 이미 목록이 있는 폴더에서 다른 폴더로 옮기는 중이라면 종전 목록이 그대로 남습니다
- **새로 만들기**: 패널 메뉴의 `새 폴더`·`새 파일`로 표시 중인 폴더에 만듭니다. 이름이 겹치면 `(2)`, `(3)`… 번호가 붙고 **기존 항목을 덮어쓰지 않습니다**. 만들기는 워커 스레드에서 수행하며 실패하면 사유가 목록 위에 표시됩니다
- **탐색**: 주소창 경로 입력(Enter), 뒤로/앞으로/상위(`Alt+←/→/↑`), 더블클릭 폴더 진입·파일 실행, 잘못된 경로 입력 시 현 위치 유지. **목록 첫 줄의 `..`를 더블클릭해도 위 폴더로 갑니다** — 로컬·원격 목록 모두에 있으며, 올라갈 곳이 없는 드라이브 루트(`C:\`)에서는 나오지 않습니다
- **폴더 트리**: 패널별 토글(상태 줄 왼쪽 끝의 트리 아이콘 버튼 — 마우스를 올리면 `폴더 트리`/`원격 트리`가 뜹니다) — 드라이브 루트에서 지연 확장(하위 1단계만 워커 열거), 노드 클릭 시 활성 탭 이동 (단방향). 줄마다 **탐색기와 같은 셸 아이콘**이 붙고 드라이브는 `로컬 디스크 (C:)` 같은 **셸 표시 이름**으로 보입니다(이름을 얻지 못하면 `C:\` 같은 경로로 보입니다). 원격 트리는 서버에서 아이콘을 얻을 수 없어 모든 줄이 같은 폴더 아이콘입니다. **닿지 못하는 네트워크 드라이브 줄에는 아이콘 오른쪽 아래에 연결 끊김 표식(빨간 원 안의 흰 X)이 겹칩니다** — 탐색기와 같은 표시이며 누르기 전에도 보입니다(로컬 드라이브와 닿는 네트워크 드라이브에는 붙지 않습니다). 이 판정은 앱이 뜰 때 워커가 한 번 하고, 그 드라이브를 열어 볼 때 갱신됩니다 — 연결이 되살아나면 그 드라이브를 한 번 열어야 표식이 사라집니다
- **즐겨찾기**: 로컬 폴더 트리 **맨 위**에 `즐겨찾기` 제목과 함께 자주 쓰는 폴더를 모아 둡니다. **`바탕 화면`·`다운로드`는 처음부터 맨 위에 서 있고 뺄 수 없습니다**(그 줄은 우클릭해도 메뉴가 뜨지 않습니다. 폴더를 옮겼어도 윈도우에 물어 옮긴 자리를 가리키며, 그 폴더가 없는 PC에서는 해당 줄만 빠집니다). 트리 항목을 우클릭해 `즐겨찾기에 담기`로 담고(이미 담긴 폴더면 그 메뉴가 흐리게 보입니다), 사용자가 담은 즐겨찾기 줄을 우클릭해 `해제`로 뺍니다. 목록과 아래 트리 사이에는 가로 구분선이 서고, **하나도 없으면 제목도 목록도 구분선도 나오지 않습니다**. 사용자가 담은 항목은 폴더 이름으로, 기본 두 줄은 윈도우가 쓰는 이름(`바탕 화면`)으로 보이며 마우스를 올리면 전체 경로가 뜨고, 누르면 활성 탭이 그 폴더로 갑니다. **목록은 앱에 하나뿐이라 모든 워크스페이스·패널·탭이 같은 것을 보고** 재시작해도 남습니다. **원격 트리에는 즐겨찾기가 없습니다**
- **항목 수 표시**: 목록 위 오른쪽 끝에 `폴더 20 파일 10` 형식으로 폴더·파일 개수를 나눠 보입니다. 상위 이동(`..`) 줄은 이 폴더에 든 것이 아니라 세지 않습니다
- **원격 연결 (FTP·FTPS·SFTP)**: 사이드바 `+`(연결 메뉴)나 사이트 관리자에서 사이트를 등록해 **원격 탭**을 엽니다. 원격 탭은 로컬 탭과 같은 자리에서 같은 목록·정렬·보기 모드를 쓰며, 탭 배지가 연결 단계(`연결 없음`·`연결 중…`·프로토콜 이름)를 보입니다. 주소창에 `ftp://`·`sftp://` 주소를 넣어 바로 열 수도 있습니다. 사이드바에 사이트가 하나도 없으면 그 자리에 `+ 를 눌러 서버를 등록하세요`가 서고, 사이트 행 우클릭의 **`사이드바에서 숨기기`**는 목록에서 감출 뿐이라 사이트는 사이트 관리자에 그대로 남습니다(숨긴 뒤 그 사실을 알리는 알림이 뜹니다). 연결에 실패하면 서버가 준 사유와 함께 **그 실패에 맞는 안내**가 붙고(연결 실패면 암호화 설정, 로그인 거절이면 사용자 이름·비밀번호, 지문 문제면 지문 확인), 주 동작인 `재시도`가 굵게 강조됩니다
- **사이트 관리자**: 이름·프로토콜(FTP/FTPS/SFTP)·호스트·포트·로그온 유형(익명/일반)·사용자·비밀번호·전송 모드·동시 연결 수 제한·문자 인코딩을 다룹니다. **비밀번호는 Windows DPAPI로 봉인해** 저장하며 파일에는 평문이 남지 않습니다(다른 PC로 설정을 옮기면 다시 입력받습니다). SFTP는 서버 지문을 처음 볼 때 확인을 받고, 지문이 바뀌면 경고합니다. **`삭제(D)`는 확인 대화를 거칩니다** — 주소와 로그인 정보가 함께 사라지고 되돌릴 수 없기 때문입니다. 전송 모드 세 선택지(`기본`·`능동형`·`수동형`)에는 무슨 일이 일어나는지 알려 주는 설명이 툴팁으로 붙습니다
- **전송 큐**: 목록 사이 **끌어다 놓기**(로컬 ↔ 원격, 폴더는 하위까지 펼쳐서)와 원격 메뉴의 `받기`·`올리기`로 큐에 담깁니다. 어디로 갈지는 **전송 대상 탭**이 정합니다 — 마지막으로 누른 패널의 활성 탭이 그 종류(로컬/원격)의 목적지가 되고, 그 탭은 폴더 아이콘 대신 **받기(↓)·올리기(↑) 아이콘**을 답니다(다른 탭을 보는 동안에도 유지됩니다). 담기 전에 **대상에 같은 이름이 있는지 확인**해 있으면 목록을 보여 주고 `덮어쓰기`·`건너뛰기`·`취소`를 묻습니다 — 세 버튼은 그 전송 전체에 한 번에 적용되고, 답하기 전에는 아무것도 큐에 들어가지 않습니다(대상을 조회하지 못하면 확인을 건너뛰고 전송합니다). 하단 도크의 큐 화면에서 진행률·속도·남은 시간을 보고 일시 정지·취소·다시 시도할 수 있으며(도크 탭은 `전송 큐`·`성공`·`실패` 세 필터를 모아 두고 구분선 뒤에 `서버 로그`가 섭니다, 우측 아이콘 넷에는 툴팁이 붙고 멈춘 동안에는 일시 정지 아이콘이 다시 시작 모양으로 바뀝니다, 크기는 파일 목록과 같은 규칙으로 보입니다 — 다만 서버가 크기를 알리지 않으면 `—`입니다, 보일 것이 없으면 `아직 전송한 파일이 없습니다`가 섭니다), 끊긴 전송은 `.part` 파일에서 **이어받습니다**. **아래 줄의 연결별 탭(`전체`·서버별)에 붙는 건수는 지금 고른 필터를 따릅니다** — `성공` 탭이면 성공 건수, `실패` 탭이면 실패 건수이고, 그 필터에 걸리는 항목이 없는 서버도 탭 자리는 남습니다(`서버 로그` 화면에서는 셀 대상이 없어 건수를 적지 않습니다). **행을 우클릭하면 그 상태에 맞는 메뉴가 뜹니다** — 실패한 행은 `다시 시도`·`전체 다시 시도`·`삭제`·`전체 삭제`, 끝난 행은 `삭제`·`전체 삭제`, 진행 중·대기 행은 `전송 취소`·`전체 삭제`입니다(`전송 취소`와 `삭제`는 하는 일이 같아 상태별로 한 쪽만 보이고, `전체 다시 시도`는 보이는 목록에 실패가 있을 때만 섭니다). **`전체 …`의 대상은 지금 보고 있는 목록** — 위 필터와 아래 연결별 탭이 함께 거른 그것입니다. **큐 표의 열 폭도 경계를 끌어 조절**할 수 있고(구분선·가이드는 파일 목록과 같습니다) 세션에 저장됩니다 — 폭 합이 표보다 좁으면 마지막 `상태` 열이 남는 자리를 채웁니다. 상태 표시줄에 전체 진행과 실패 건수가 요약됩니다
- **원격 파일 작업**: 원격 목록 우클릭 메뉴로 `받기`·`올리기`·`이름 바꾸기`·`권한 변경`(8진 3자리 ↔ 체크박스 9개)·`삭제`·`새 폴더`·`새로 고침`. `받기`·`올리기`의 목적지는 위 **전송 대상 탭**이 정하고, 대상이 없으면 그 항목이 비활성입니다. **삭제는 확인 대화를 거치며**, 파일이면 파일 삭제 명령을·폴더면 폴더 삭제 명령을 앱이 알아서 보냅니다(안에 든 것까지 지우는 재귀 삭제는 없습니다 — 비어 있지 않은 폴더는 서버가 거절하고 그 사유가 남습니다). 서버가 지원하지 않는 작업(예: `SITE CHMOD`)은 사유가 상태 표시줄과 서버 로그에 남습니다
- **원격 트리·서버 로그**: 같은 토글이 원격 패널에서는 `원격 트리`(툴팁)가 되어 서버 폴더를 지연 확장하고(한 번 읽은 폴더는 다시 묻지 않습니다), 하단 도크의 `로그` 화면에 서버와 주고받은 명령·응답이 남습니다(비밀번호는 가려집니다). 로그는 **마우스로 끌어 원하는 부분만 골라 복사**할 수 있고(`Ctrl+C`), `⧉`로 통째로 복사할 수도 있습니다 — 화면에 보이는 줄이 선택 대상이며 긴 줄은 `…`로 잘려 보이지만 그 줄을 전부 고르면 원문이 복사됩니다
- **셸 컨텍스트 메뉴**: 우클릭(다중 선택 지원)으로 Windows 표준 메뉴 — 복사·삭제·속성·보내기 등 파일 작업 전부 셸 위임, 빈 영역 우클릭은 폴더 배경 메뉴(새로 만들기 — 목록이 화면을 다 채우지 않을 때)
- **변경 자동 새로고침**: 표시 중 폴더를 감시(ReadDirectoryChangesW)해 외부 변경 시 300ms 디바운스 후 자동 갱신, `F5` 수동 새로 고침
- **세션 저장/복원**: 종료 시 워크스페이스 목록·각 워크스페이스의 분할 구성과 탭(로컬 경로·**원격 사이트와 경로**)·**패널별 보기 모드와 열 폭**·**전송 큐 표의 열 폭**·사이드바 폭/접힘·창 위치/최대화에 더해 **등록한 사이트·끝나지 않은 전송 큐·도크 상태**를 `%APPDATA%\MOA\settings.json`에 저장, 재시작 시 복원합니다. **재시작해도 서버에 자동으로 연결하지 않고 전송도 스스로 재개하지 않습니다** — 원격 탭은 `연결 없음`으로, 큐는 대기·실패인 채로 섭니다. 되살아난 원격 탭은 **`다시 연결` 버튼**을 보이며, 누르면 그 사이트로 붙어 저장된 폴더의 목록을 바로 보입니다(사이트를 지운 뒤 남은 탭은 붙을 곳을 모르므로 종전대로 주소 입력 안내를 보입니다). **화면이 여럿이면 지난번 그 화면에 되살립니다** — 화면마다 배율이 달라도 창이 있던 쪽을 찾아 그 화면의 작업 영역만 하게 띄우고, 그 화면을 뽑았거나 배치가 바뀌어 저장된 자리가 어디에도 없으면 주 화면 안으로 들여옵니다. 옛 형식(v2) 파일은 그대로 승격되어 살아납니다. 재시작 직후에는 **활성 워크스페이스의 탐색기만 생성**하고 나머지는 선택할 때 만듭니다(메모리 절약). 손상·구버전 파일은 기본 레이아웃으로 폴백합니다
- **다크 테마**: 창 전체(타이틀바·파일 목록·폴더 트리·주소창·탭·워크스페이스 사이드바)를 고정 다크 스타일로 표시합니다(전환 UI 없음). 타이틀바는 앱이 직접 그리고, 패널 메뉴 팝업도 앱 팔레트를 따릅니다. 우클릭 셸 메뉴는 Windows 다크 정책을 따릅니다
- **팝업 공통 규격**: 확인·입력 대화부터 설정·사이트 관리자까지 **모든 팝업이 같은 모양**입니다 — 네 모서리가 둥글고(12px), 하단 버튼은 팝업 좌우 끝까지 닿아 개수만큼 균등하게 나뉘며 그 사이를 가는 구분선이 가릅니다. 마우스를 올린 칸만 배경이 밝아지고, 그 대화의 주 동작(`확인`·`삭제`·`연결` 등)은 글자가 굵습니다. 본문은 버튼 줄에서 한 칸 떨어져 있어 목록·표의 테두리가 버튼 구분선과 겹쳐 보이지 않습니다. 글자를 받는 팝업(`이름 바꾸기`·`새 폴더`·`권한 변경`의 8진수 칸)의 입력칸은 **테두리를 두른 어두운 웰**이라 포커스가 없어도 어디에 입력하는지 보이며, 사이트 관리자 폼의 입력 필드와 같은 규격입니다. 이 규격은 `src/ui/dialog.rs` 한 곳에 있어 앞으로 더할 팝업도 자동으로 같은 모양이 됩니다
- **한국어·영어 UI**: 화면 문구는 한 곳(`src/i18n`)의 카탈로그를 거칩니다 — 키 하나에 두 언어를 함께 적고, 한쪽을 빠뜨리면 컴파일되지 않습니다. 서버가 보낸 응답 원문(`530 Login incorrect` 등)과 FTP 명령어는 번역하지 않고 그대로 싣습니다

**설정 화면 추가 후 실측 (release, 2026-08-14, 기본 레이아웃·5회 중앙값)**: 시작→창 표시 277ms · 유휴 메모리 173.8MB · exe 7.69MB(추가 전 7.14MB). 유휴 메모리가 NFR-2 기준(150MB)을 넘지만 **설정 화면 작업이 낸 회귀는 아닙니다** — 이 기능이 **하나도 들어가지 않은 직전 커밋**(`6fe19e0`)을 같은 PC·같은 조건(설정 파일을 지운 기본 레이아웃, 5회 중앙값)으로 따로 빌드해 재니 **172.9MB**로 사실상 같았습니다(시작 시간도 378ms로 오히려 느렸습니다). 트레이·글꼴·자동 실행을 하나씩 빼 보는 추가 분리는 하지 않았습니다 — 전체를 넣은 것과 뺀 것의 차이가 0.9MB(측정 편차 범위)라 나눌 몫이 없기 때문입니다. **2026-08-05 측정치(127.9MB)와의 45MB 차이는 원인을 밝히지 못했고**, 같은 코드에서도 그만큼 나오므로 측정 환경(그래픽 드라이버·OS 상태)이 달라진 몫으로 보고 있습니다.

핵심 플로우: 탐색 요청 → `PanelState::navigate`(pending 등록, 세대 번호 증가) → 워커 스레드 열거 → 채널 수신 후 프레임에서 반영 → 경로·히스토리 커밋 → 커밋된 폴더로 변경 감시 교체. **폴더를 열지 못했을 때도 그 폴더까지 옮깁니다** — 주소창·트리와 목록이 갈리지 않도록 경로는 커밋하되 목록을 비우고 그 자리에 사유를 적으며(올라갈 곳이 있으면 첫 줄 `..`만 남습니다 — 드라이브 뿌리에는 그 줄도 없습니다), 읽지 못한 폴더는 감시하지 않습니다. 사유는 세 갈래로 갈라 적습니다: `이 폴더를 열 권한이 없어 내용을 표시할 수 없습니다` / `네트워크 드라이브에 연결할 수 없어 내용을 표시할 수 없습니다` / `이 폴더를 여는 중 문제가 생겨 내용을 표시할 수 없습니다`. **폴더를 찾을 수 없는 경우만** 현 위치·목록을 지키고 상태 줄에 사유를 알립니다(실재하지 않는 곳에는 옮길 자리가 없습니다). 파일 작업(복사·삭제 등)은 셸 컨텍스트 메뉴에 위임하며, 이 메뉴는 자체 메시지 루프를 돌리므로 프레임 그리기가 모두 끝난 뒤에 띄웁니다. 종료 시 세션 수집·저장, 시작 시 복원.

원격 플로우: 사이트 선택 → 워커 스레드 하나가 그 연결을 맡고(탐색 1 + 전송 N채널), 화면은 **채널만 폴링**합니다 — 서버가 응답하지 않아도 다른 패널·다른 사이트는 계속 움직입니다. 목록·전송·파일 작업은 전부 명령으로 나가고 결과는 이벤트로 돌아오며, 늦게 온 지난 요청의 답은 세대 번호로 걸러집니다. 전송은 64KB씩 흘려보내 파일 크기와 무관하게 메모리가 버퍼 몫에 머물고, 끊기면 `.part`의 크기에서 이어받습니다.

워크스페이스 플로우: 사이드바 클릭 → 그 워크스페이스가 활성이 되고, **처음 선택이면** 저장된 구성으로 분할·탭을 만듭니다(지연 생성 — 방문하지 않은 워크스페이스는 패널도 열거 스레드도 없습니다). 이미 만든 워크스페이스는 상태를 그대로 갖고 있어 스크롤·선택이 유지됩니다. 활성 패널의 폴더가 바뀌면 사이드바 카드의 둘째 줄이 따라 갱신됩니다.
