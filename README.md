# FileExplorer — 멀티 분할 경량 파일 탐색기

Windows 11 이상(x64)에서 하나의 창을 **자유 분할(트리형)**하고, 각 패널이 **독립 탭**을 가지며, 좌측 **워크스페이스 목록**으로 여러 벌의 탐색기 화면을 전환하는 초경량 파일 탐색기입니다. Rust(windows-rs)로 Win32 API를 직접 호출해 GUI 프레임워크 없이 구현했습니다 (Q-Dir의 멀티 패널 + VS Code의 자유 분할 UX 참고).

## 핵심 기능

- **워크스페이스**: 좌측 사이드바에서 워크스페이스를 만들면(`+` 버튼·워크스페이스 메뉴) 그 워크스페이스만의 탐색기 화면이 생기고, 항목을 고르면 즉시 전환됩니다. 워크스페이스마다 분할 구성·패널·탭·히스토리가 완전히 독립이며, 항목은 이름과 현재 폴더 경로를 2줄로 보여줍니다. 이름 바꾸기(`F2`·우클릭), 삭제(확인 후 — 마지막 1개는 불가), 드래그로 순서 변경을 지원합니다
- **사이드바 조절**: 경계선 드래그로 폭 변경(160~480px), `Ctrl+B`·보기 메뉴·상단 버튼으로 접기/펼치기 (접힌 상태·폭도 저장됩니다)
- **자유 분할**: 활성 패널을 좌우/상하로 중첩 분할 (보기 메뉴, `Ctrl+\` 좌우, `Ctrl+Shift+\` 상하), 스플리터 드래그로 비율 조절, `Ctrl+Shift+W` 패널 닫기 (마지막 1개는 닫기 불가)
- **패널별 탭**: `Ctrl+T` 새 탭(현재 경로 복제), `Ctrl+W` 탭 닫기(마지막 탭은 패널 닫기로 연결), 탭 클릭 전환, 탭별 독립 히스토리
- **파일 목록**: 상세 보기(이름·크기·종류·수정한 날짜), 열 클릭 정렬(탐색기와 동일한 숫자 인지 정렬·폴더 우선), 시스템 아이콘, 가상 리스트뷰 + 백그라운드 열거(대량 폴더 UI 무정지)
- **탐색**: 주소창 경로 입력(Enter), 뒤로/앞으로/상위(`Alt+←/→/↑`), 더블클릭 폴더 진입·파일 실행, 잘못된 경로 입력 시 현 위치 유지
- **폴더 트리**: 패널별 토글(보기 > 폴더 트리) — 드라이브 루트에서 지연 확장(하위 1단계만 워커 열거), 노드 클릭 시 활성 탭 이동 (단방향)
- **셸 컨텍스트 메뉴**: 우클릭(다중 선택 지원)·메뉴 키로 Windows 표준 메뉴 — 복사·삭제·속성·보내기 등 파일 작업 전부 셸 위임, 빈 영역 우클릭은 폴더 배경 메뉴(새로 만들기)
- **변경 자동 새로고침**: 표시 중 폴더를 감시(ReadDirectoryChangesW)해 외부 변경 시 300ms 디바운스 후 자동 갱신, `F5` 수동 새로 고침
- **세션 저장/복원**: 종료 시 워크스페이스 목록·각 워크스페이스의 분할 구성과 탭 경로·사이드바 폭/접힘·창 위치/최대화를 `%APPDATA%\FileExplorer\settings.json`에 저장, 재시작 시 복원. 재시작 직후에는 **활성 워크스페이스의 탐색기만 생성**하고 나머지는 선택할 때 만듭니다(메모리 절약). 손상·구버전 파일은 기본 레이아웃으로 폴백합니다
- **다크 테마**: 창 전체(타이틀바·메뉴바·파일 목록·폴더 트리·주소창·탭·워크스페이스 사이드바)를 고정 다크 스타일로 표시합니다(전환 UI 없음). 사이드바 폭 조절 시 사이드바와 탐색기가 한 번에 배치되고 더블버퍼링으로 그려져 잔상 없이 움직입니다 (메뉴 팝업 배경 일부는 Windows 제약상 시스템 색이 남을 수 있음)
- 긴 경로(260자+)·유니코드 파일명, Per-Monitor v2 DPI, 한국어 UI

**성능 실측 (release, 2026-07-24)**: 시작→창 표시 중앙값 258ms · 1워크스페이스·2패널 유휴 메모리 23.6MB · 워크스페이스 5개 방문 유휴 24.1MB · 10만 파일 폴더 진입 중 UI 응답 유지(2026-07-23 측정) — PRD NFR-1~3·NFR-8 충족

## 실행 방법

```
cargo run              # 디버그 실행
cargo build --release  # 배포 빌드 (단일 exe, 약 380KB)
```

요구 사항: Rust stable(1.80+, msvc 툴체인), Windows 11 이상.

검증: `cargo test`(단위테스트), `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`

## 아키텍처

계층형 단일 crate — 모듈 분리 (상세 규약은 `AGENTS.md`, 요구사항 정본은 `docs/prd.md`):

```
src/
├── main.rs            # 진입점 — COM 초기화, 액셀러레이터, 메시지 루프
├── lib.rs             # 라이브러리 타깃 — 통합 테스트(tests/)용 모듈 재수출
├── app/
│   ├── window.rs      # 메인 창 — 워크스페이스 소유·전환, 명령 라우팅, 사이드바 폭·세션 훅
│   ├── workspace.rs   # 워크스페이스 목록 모델 (순수 로직 — 추가/이름/삭제/정렬/부제)
│   ├── sidebar.rs     # 좌측 다크 카드 목록 창 (직접 그리기 — 선택·인라인 편집·드래그 정렬)
│   ├── layout.rs      # 분할 레이아웃 트리 (순수 로직 — split/close/비율/배치/스냅숏)
│   ├── layout_host.rs # 트리 → 자식 HWND 배치(영역 주입), 스플리터 드래그, 표시 토글·일괄 파괴
│   ├── settings.rs    # 세션 직렬화 v2 (serde — 워크스페이스 배열·사이드바 상태)
│   └── menu.rs        # 한국어 메뉴 바·단축키 테이블
├── panel/
│   ├── panel.rs       # 패널 컨테이너 — pending-커밋 탐색 조율, 감시·세션 배선
│   ├── tabs.rs        # 탭 모델(순수)+WC_TABCONTROL 래퍼
│   ├── file_list.rs   # SysListView32 가상 모드 — 표시·정렬·선택 조회
│   ├── folder_tree.rs # SysTreeView32 폴더 트리 — 지연 확장(워커 열거)
│   ├── address_bar.rs # 주소창(버튼+Edit)·경로 정규화
│   └── history.rs     # 탭별 탐색 히스토리 (순수 로직)
├── fs/
│   ├── enumerate.rs   # 워커 스레드 디렉터리 열거 (FindFirstFileExW, \\?\ 긴경로)
│   ├── icons.rs       # 셸 아이콘·종류 캐시 (시스템 이미지 리스트 공유)
│   ├── shell_menu.rs  # IContextMenu 셸 컨텍스트 메뉴 (COM — unsafe 격리)
│   └── watcher.rs     # 폴더 변경 감시 (ReadDirectoryChangesW + 디바운스)
└── tests/
    └── watcher.rs     # 감시 통합 테스트 (HWND 비의존 — 채널 검증)
```

핵심 플로우: 탐색 요청 → `Panel::navigate`(pending 등록, 세대 토큰 증가) → 워커 스레드 열거 → 채널+`WM_APP` 통지 → 성공 시에만 경로·히스토리 커밋 (실패 시 현 위치 유지) → 커밋 경로로 변경 감시 재시작. 파일 작업(복사·삭제 등)은 셸 컨텍스트 메뉴에 위임. 종료(WM_CLOSE) 시 세션 수집·저장, 시작 시 복원.

워크스페이스 플로우: 사이드바 클릭 → 메인 창이 해당 워크스페이스를 활성화 → 처음 선택이면 저장된 구성으로 탐색기를 만들고(지연 생성), 이미 만들어져 있으면 숨김 해제만 → 이전 워크스페이스는 창을 파괴하지 않고 숨겨 두어 스크롤·선택 상태가 유지됩니다. 폴더를 이동하면 활성 패널이 메인 창에 알려 사이드바의 경로 줄이 갱신됩니다.
