# PRD: MOA — 멀티 분할 경량 파일 탐색기

작성일: 2026-07-23
상태: 승인됨 (2026-07-23)

## 목적

Windows 11 이상에서 하나의 창을 여러 패널로 자유 분할하고, 각 패널이 독립 탭을 가지는 **경량 파일 탐색기**. Q-Dir의 멀티 패널 개념 + VS Code의 자유 분할 UX를 결합한다. 개발 언어는 Rust, 개인 사용 목적.

UI는 **egui(eframe/glow)** 로 그리고, 셸 연동(시스템 아이콘·컨텍스트 메뉴·디렉터리 변경 감시·파일 실행)은 windows-rs로 유지한다. 시작 속도는 네이티브 수준을 유지하되(NFR-1), 메모리는 GUI 프레임워크의 바닥값을 감안한 기준을 쓴다(NFR-2 — 2026-07-26 결정 이력 참조).

| FR-8 | 우클릭 시 Windows 셸 컨텍스트 메뉴를 표시한다 (복사·삭제 등 파일 작업은 셸에 위임) | Must | HUMAN-VERIFY |

| FR-11 | 종료 시 분할 레이아웃·탭·창 위치를 저장하고 재시작 시 복원한다 | Should | 단위테스트: 세션 직렬화/역직렬화 왕복 검증 + 복원 화면은 HUMAN-VERIFY |

### 원격 연결 (FTP/FTPS/SFTP) — 2026-08-04 추가

> 기준 문서: `docs/design/README.md`(디자인 명세 정본, High fidelity) + `docs/design/design-files/*.dc.html`.
> 원격 서버는 **별도 앱 모드가 아니라 패널의 한 종류**다 — 로컬 패널과 같은 화면 부품(ExplorerPane)이 원격 목록을 그린다.

| ID | 요구사항 | 우선순위 | 검증 방법 |
|----|---------|---------|----------|
| FR-27 | **사이트 관리자**로 원격 사이트를 등록·수정·삭제한다. '일반' 탭 필드는 프로토콜(T)·호스트(H)+포트(P)·암호화(E)·로그온 유형(L)·사용자(U)·비밀번호(W)이며, 좌측 목록은 루트 노드 없는 평면 목록 + `이름 바꾸기(R)`·`삭제(D)`·`복제(I)` 버튼. 바닥은 `연결(C)`(등록 후 즉시 연결)·`확인(O)`(등록만)·`취소` | Must | 단위테스트: 사이트 레코드 CRUD·중복 이름 회피 검증 + 화면은 HUMAN-VERIFY |

| FR-56 | **폴더 트리에 즐겨찾기**를 둔다 — 로컬 트리 맨 위에 `즐겨찾기` 제목(흐린 작은 글씨)을 세우고 그 아래 등록한 폴더들을 더한 차례대로 보이며 목록 아래를 가로 구분선으로 가른다(하나도 없으면 제목도 목록도 구분선도 그리지 않는다). **맨 위 두 줄은 윈도우가 정해 준 `바탕 화면`·`다운로드`가 기본으로 서고 해제할 수 없다**(그 줄은 우클릭해도 메뉴가 뜨지 않으며, 실재하지 않는 폴더는 빠진다. 이름은 윈도우가 쓰는 것을 그대로 보이고, 폴더를 다른 드라이브로 옮겼어도 옮긴 자리를 가리킨다. 세션 파일에는 담기지 않아 사용자 항목과 섞이지 않는다). 트리 항목을 우클릭한 메뉴의 `즐겨찾기에 담기`로 담고(이미 담긴 폴더면 그 줄이 비활성), 즐겨찾기 줄을 우클릭한 메뉴의 `해제`로 뺀다. **사용자가 담은** 항목은 폴더 이름만 보이고 전체 경로는 툴팁이 들며, 누르면 활성 탭이 그 폴더로 간다. **목록은 앱에 하나뿐이라 모든 워크스페이스·패널·탭이 같은 것을 보고** 세션 파일에 담겨 재시작해도 남는다. **원격 트리는 대상이 아니다**(원격 폴더는 담지 않고 그 트리에는 메뉴도 뜨지 않는다) | Should | 단위테스트: 저장소의 추가·중복·해제·순서와 세션 왕복, 메뉴 줄의 활성 규칙·조작 전달 검증 + 화면은 HUMAN-VERIFY |

## 결정 이력

- 2026-08-18: **전송 큐 조작 확장·열 폭 조절·크기 표기 통일**(FR-4·FR-36·FR-40 문면 개정, 사용자 승인). plan `docs/plans/2026-08-18-queue-menus-and-size-display.md`
  - **크기 표기를 한 벌로 접는다**(FR-4) — 파일 목록(KB 고정)과 전송 큐(KB/MB/GB)로 갈려 있던 규칙을 `소수 둘째자리 + 자동 승격` 하나로 합쳤다. 승격은 **반올림한 값**으로 판정하고(아니면 `1024.00 KB`가 나온다), 0이 아닌 값은 최소 `0.01 KB`를 채운다(빈 파일과 구분). 큐에서만 0이 "크기를 모른다"라 `—`다.
  - **연결별 탭 건수가 필터를 따른다**(FR-36) — `성공` 탭(0건)인데 아래 줄이 `전체 (1)`이던 것을 고쳤다. **탭 멤버십은 거르지 않는다** — 그 필터에 항목이 없는 서버까지 사라지면 고를 수 없다.
  - **행 메뉴는 탭이 아니라 행 상태가 정한다**(FR-36) — `전송 취소`와 `삭제`는 동작이 같아(전송 중단 + 목록 제거 + `.part` 삭제) 나란히 두면 헷갈리므로 한 쪽만 보인다. `전체 …`의 대상은 눈에 보이는 목록이다.
  - **큐 표의 흡수 열을 `로컬 파일`에서 마지막 `상태`로 옮겼다**(FR-36) — 흡수 열이 앞자리면 그 오른쪽 경계를 끌어도 흡수분이 같은 양을 반대로 먹어 잡은 경계가 제자리에 서고, 열 폭 조절 자체가 성립하지 않는다. 대가로 창을 넓혔을 때 늘어나는 열이 바뀐다(디자인 원본의 `1fr` 배치와 달라진다).
