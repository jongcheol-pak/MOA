# PRD: FileExplorer — 멀티 분할 경량 파일 탐색기

작성일: 2026-07-23
상태: 승인됨 (2026-07-23)

## 목적

Windows 11 이상에서 하나의 창을 여러 패널로 자유 분할하고, 각 패널이 독립 탭을 가지는 **초경량 파일 탐색기**. Q-Dir의 멀티 패널 개념 + VS Code의 자유 분할 UX를 결합하되, 메모리·시작 속도는 네이티브(Q-Dir) 수준을 목표로 한다. 개발 언어는 Rust(windows-rs, Win32 API 직접), 개인 사용 목적.

## 기능 요구사항 (Functional Requirements)

| ID | 요구사항 | 우선순위 | 검증 방법 |
|----|---------|---------|----------|
| FR-1 | 활성 패널을 좌우 또는 상하로 자유 분할할 수 있다 (트리형 중첩 분할, VS Code 방식) | Must | 단위테스트: 레이아웃 트리 split 연산 → 노드 구조 검증 + 화면은 HUMAN-VERIFY |
| FR-2 | 스플리터 드래그로 패널 크기를 조절하고, 패널을 닫을 수 있다 (마지막 1개 패널은 닫기 불가) | Must | 단위테스트: 트리 close/비율 연산 검증 + 드래그는 HUMAN-VERIFY |
| FR-3 | 패널마다 독립 탭을 가진다 (추가/닫기/전환, 탭별 독립 탐색 히스토리) | Must | 단위테스트: 탭 상태·히스토리 모델 검증 + UI는 HUMAN-VERIFY |
| FR-4 | 파일 목록을 상세 보기(이름·크기·종류·수정일)로 표시하고 열 클릭으로 정렬한다 | Must | 단위테스트: 정렬 비교 로직 검증 + 표시는 HUMAN-VERIFY |
| FR-5 | 파일·폴더에 시스템 아이콘을 표시한다 | Must | HUMAN-VERIFY (셸 이미지 리스트 연동 코드 확인 병행) |
| FR-6 | 주소창에 경로를 입력해 이동하고, 뒤로/앞으로/상위 버튼으로 탐색한다 | Must | 단위테스트: 히스토리 push/back/forward 로직 검증 + UI는 HUMAN-VERIFY |
| FR-7 | 더블클릭 시 폴더는 진입, 파일은 연결 프로그램으로 실행한다 (`ShellExecuteEx`) | Must | HUMAN-VERIFY (분기 로직은 단위테스트) |
| FR-8 | 우클릭 시 Windows 셸 컨텍스트 메뉴를 표시한다 (복사·삭제 등 파일 작업은 셸에 위임) | Must | HUMAN-VERIFY |
| FR-9 | 폴더 트리를 패널별로 토글 표시한다 (지연 확장 방식) | Should | HUMAN-VERIFY (트리 노드 열거 로직은 단위테스트) |
| FR-10 | 표시 중인 폴더의 변경(생성·삭제·이름변경)을 자동 새로고침한다 (`ReadDirectoryChangesW`) | Should | 통합테스트: 임시 폴더에 파일 생성 → 목록 갱신 이벤트 수신 검증 |
| FR-11 | 종료 시 분할 레이아웃·탭·창 위치를 저장하고 재시작 시 복원한다 | Should | 단위테스트: 세션 직렬화/역직렬화 왕복 검증 + 복원 화면은 HUMAN-VERIFY |
| FR-12 | 기본 단축키를 지원한다 (Ctrl+T 새 탭, Ctrl+W 탭 닫기, Alt+←/→ 히스토리, F5 새로고침, Ctrl+\\ 좌우 분할, Ctrl+Shift+\\ 상하 분할) | Should | HUMAN-VERIFY |
| FR-13 | 숨김·시스템 파일 표시를 토글할 수 있다 | Could | 단위테스트: 필터 로직 검증 |
| FR-14 | 분할 프리셋 버튼(1 / 좌우2 / 상하2 / 4분할)으로 레이아웃을 한 번에 전환할 수 있다 (Q-Dir식, 트리 재구성 헬퍼) | Could | 단위테스트: 프리셋 → 트리 구조 검증 |

우선순위: Must(없으면 미완성) / Should(중요하나 1차 출시 후 가능) / Could(여유 시)

## 비기능 요구사항 (Non-Functional)

| ID | 요구사항 | 검증 방법 |
|----|---------|----------|
| NFR-1 | 콜드 스타트 1초 미만 | 실행 → 창 표시까지 측정 |
| NFR-2 | 유휴 메모리 50MB 미만 (패널 2개·일반 폴더 기준) | 작업 관리자/스크립트로 Working Set 측정 |
| NFR-3 | 파일 10만 개 폴더도 UI 멈춤 없이 표시 (가상 리스트뷰 + 백그라운드 열거) | 테스트 폴더 생성 스크립트로 10만 파일 생성 후 체감·응답성 확인 |
| NFR-4 | Per-Monitor v2 DPI 지원 | 서로 다른 배율 모니터 간 이동 확인 (HUMAN-VERIFY) |
| NFR-5 | 긴 경로(260자 초과)·유니코드 파일명 지원 | 테스트 폴더로 확인 |
| NFR-6 | UI 문구는 한국어 고정 (v1) | 화면 문구 확인 |
| NFR-7 | 설정·세션은 `%APPDATA%\FileExplorer\settings.json`에 저장 | 파일 생성 확인 |

## Out of Scope (명시적 제외)

- 자체 파일 작업 UI (복사/이동/삭제 진행률 창 — v1은 셸 컨텍스트 메뉴에 위임)
- 드래그 앤 드롭, 잘라내기/붙여넣기 자체 구현
- 파일 검색, 이름 필터
- 다크 모드, 테마
- 즐겨찾기, 세션 프로필 다중 관리
- 셸 네임스페이스 가상 폴더 (휴지통·제어판·네트워크 위치 등 — 파일시스템 경로만 지원)
- 다국어 리소스 (v1은 한국어 고정)

## 성공 기준

- Must 요구사항(FR-1~FR-8) 100% 충족
- Should(FR-9~FR-12) 80% 이상
- NFR-1~NFR-3 실측 통과 (시작 1초·메모리 50MB·10만 파일 무정지)
