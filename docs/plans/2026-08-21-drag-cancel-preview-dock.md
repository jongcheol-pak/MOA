# Plan: 같은 폴더 드롭 취소 · 앱 안 드래그 미리보기 그림 · 도크 시작 상태

**PRD**: `docs/prd.md`

## 요구 이해

- **원문 요청**:
  1. *"탭에서 항목을 드래그 해서 다시 같은 탭에 놓으면 복사가 되는데 취소가 되도록 함."*
  2. *"탭에서 탭으로 항목 이동시 마우스 포인트만 변경 되는데 이때도 마우스에 미리보기 아이콘이 표시 되도록 함."*
  3. *"하단에 표시되는 전송 큐 화면을 오픈 상태로 앱을 종료하고 다시 실행하면 오픈 상태 그대로 표시 되는데 앱을 다시 실행하면 전송 큐 화면은 닫힌 상태로 표시. 트레이에서 메인 화면이 표시될 때에는 유지함."*
- **이해한 요구**:
  - ① 지금은 목록에서 끈 항목을 **그 자리(같은 폴더)** 에 놓으면 셸 복사가 걸려 `- 복사본`이 생긴다. 그 드롭은 아무 일도 하지 않아야 한다.
  - ② 앱 **안**에서 탭↔탭으로 끄는 동안에는 커서 모양(`Grabbing`)만 바뀌고 무엇을 끌고 있는지 보이지 않는다. 창 밖으로 끌어낼 때처럼 **첫 항목의 그림**이 커서를 따라와야 한다.
  - ③ 하단 도크(전송 큐·서버 로그)의 **열림 여부**가 세션에 저장돼 재시작 때 그대로 열린다. 앱을 새로 켤 때는 **언제나 닫힌 채로** 시작해야 한다. 트레이로 숨겼다가 다시 부르는 것은 같은 프로세스라 종전대로 유지된다.
- **승인 질의로 확정된 것** (2026-08-21):
  - ① 취소 판정은 **놓은 폴더 기준**이다 — 다른 탭이 같은 폴더를 보고 있어도 취소한다. 취소할 때 **아무것도 알리지 않는다**(탐색기와 같다).
  - ② 그림은 **끌어내기와 같은 규칙** — 이미 만들어 둔 썸네일이 있으면 그것, 없으면 형식 아이콘. **첫 항목 한 장**이며 개수 배지·이름 글자는 없다.
  - ③ 그림은 **앱 안 드래그 전부**에 보인다 — 로컬↔로컬 복사뿐 아니라 로컬→원격(올리기)·원격→로컬(받기) 전송 드래그에도 보인다.
  - ④ **OS(탐색기·바탕화면)에서 끌어온 것을 같은 폴더에 놓는 경로는 이번에 손대지 않는다** — 종전대로 셸이 복사한다.
- **포함하지 않는 것으로 이해**: 이동(잘라내기) 드래그 · 원격↔원격 드래그 · 사이드바 사이트 드래그의 그림 · 개수 배지·아이콘 겹쳐 쌓기 · 도크 열림 상태를 유지할지 고르는 설정 항목.

## Goal

앱 안 드래그의 세 가지 어긋남을 고친다 — ⓐ 같은 폴더에 놓은 드롭을 셸 복사로 넘기지 않고 그 자리에서 끊고, ⓑ 끄는 동안 첫 항목의 반투명 그림을 커서에 붙이고, ⓒ 하단 도크의 열림 여부를 세션에서 걷어내 앱이 언제나 닫힌 도크로 시작하게 한다.

## Out of Scope

- **OS(탐색기·바탕화면) → 같은 폴더 드롭의 취소**. 사용자가 2026-08-21에 "이번엔 그대로 둔다"를 골랐다. 그 경로(`ui::app::pump_os_drop` → `start_local_copy_paths`)는 `local_copy_target`을 거치지 않으므로 이번 변경에 영향받지 않는다.
- **이동(잘라내기) 드래그**·**원격↔원격 드래그**·**잘라내기/붙여넣기**. PRD Out of Scope(라인 116)의 영구 제외 그대로다.
- **개수 배지·항목 이름 글자·아이콘 여러 장 겹쳐 쌓기**(2026-08-21 사용자 결정 — 첫 항목 한 장).
- **사이드바 사이트→탭 드래그의 미리보기 그림**. 그 드래그의 페이로드는 `SiteId`라 파일 항목이 아니다.
- **도크 열림 상태를 유지할지 고르는 앱 설정 항목**. 요청은 "언제나 닫힌 채 시작"이지 "고를 수 있게"가 아니다.

## Decisions

### D1. 취소 판정의 축 — 놓은 폴더가 같으면 취소
- **Options**: ⓐ 놓은 폴더 기준(탭이 달라도) ⓑ 같은 탭에 놓았을 때만
- **Chosen**: ⓐ (2026-08-21 사용자 결정). 끌어온 항목들의 **부모 폴더가 전부** 놓은 폴더와 같으면 아무 일도 하지 않는다.
- **Source**: 승인 질의. ⓑ는 두 탭이 같은 폴더를 볼 때 사본이 생기는 경로를 남긴다.

### D2. 경로 견주기 — ASCII 대소문자를 접는다
- **Options**: ⓐ `Path` 그대로 견줌 ⓑ ASCII 대소문자만 접어 견줌 ⓒ 정규화(`canonicalize`)
- **Chosen**: ⓑ. `Path`의 `PartialEq`가 이미 구성요소 단위라 끝 구분자 차이는 흡수하지만 **대소문자는 흡수하지 않는다**. Windows 파일시스템은 대소문자를 가리지 않으므로 `C:\Work`와 `C:\work`는 같은 폴더다 — 주소창으로 옮긴 탭이 다른 대소문자를 들고 있을 수 있다.
- **Source**: Rust `std::path::Path`의 `PartialEq`(구성요소 비교) 확인. ⓒ는 파일시스템을 두드리는 블로킹 호출이라 매 드롭마다 부를 것이 못 된다(AGENTS DO NOT).

### D3. 취소를 알리는 방법 — 아무것도 알리지 않는다
- **Options**: ⓐ 조용히 아무 일도 하지 않음 ⓑ 상태 줄 알림 ⓒ 토스트
- **Chosen**: ⓐ (2026-08-21 사용자 결정). 탐색기가 같은 조작에서 아무것도 알리지 않는다. `ui::toast`의 성격("놓쳐도 되는 즉시 작업의 결과")에도 맞지 않는다 — 일어난 일이 없다.
- **Source**: 승인 질의 + `ui::toast` 모듈 주석.

### D4. 미리보기 그림의 출처 — 썸네일이 있으면 그것, 없으면 형식 아이콘
- **Options**: ⓐ 끌어내기와 같은 규칙(썸네일→아이콘) ⓑ 언제나 형식 아이콘 ⓒ +개수 배지 ⓓ +이름 글자
- **Chosen**: ⓐ (2026-08-21 사용자 결정). **이미 올라와 있는 텍스처만 쓴다** — 없으면 만들지 않고 아이콘으로 되돌린다. 여러 개를 끌어도 첫 항목 한 장이다.
- **Source**: 승인 질의 + 2026-08-21 결정(FR-61 ⓑ의 `SIIGBF_INCACHEONLY` → `ICONONLY` 규칙)과 같은 방향.

### D5. 그림을 그리는 주체 — 끌기를 시작한 패널
- **Options**: ⓐ 끌기를 시작한 패널이 그린다 ⓑ `ui::app`이 그린다
- **Chosen**: ⓐ. 썸네일 텍스처(`ThumbnailTextures`)가 **패널 소유**라(전제 7) 앱에서는 첫 항목의 썸네일에 닿을 길이 없다. 아이콘 캐시 둘(`IconCache`·`IconTextures`)은 이미 `show_list`에 인자로 들어온다.
- **Source**: `src/ui/panel.rs:256~258`·`:1470`.

### D6. 그림 크기 — 64 논리 픽셀
- **Options**: ⓐ 64 논리 px ⓑ 96 논리 px(끌어내기와 같은 값) ⓒ 목록 아이콘 크기를 따라감
- **Chosen**: ⓐ. 끌어내기의 96px은 바탕화면·탐색기 위에 뜨는 값이고, 앱 안에서는 행 높이가 20px 안팎인 목록 위에 뜬다 — 96px이면 다섯 줄을 덮어 어디에 놓는지가 보이지 않는다. ⓒ는 보기 모드를 바꿀 때마다 그림 크기가 달라져 같은 조작이 다르게 보인다.
- **Source**: `ui::dock::STRIP_HEIGHT`·목록 행 높이 실측 맥락. `IconSize::for_px(64.0)`는 `Jumbo`(256px 목록)를 골라 줄여 그리므로 뭉개지지 않는다(`fs::icons::IconSize::for_px` 주석).

### D7. 커서와 그림의 자리 — 커서 오른쪽 아래로 비킨다
- **Options**: ⓐ 커서 오른쪽 아래로 비킴 ⓑ 그림 중심을 커서에 맞춤
- **Chosen**: ⓐ. 중심을 맞추면 커서가 그림에 덮여 **정확히 어느 줄에 놓는지**가 보이지 않는다. 탐색기도 오른쪽 아래에 붙인다.
- **Source**: `PanelState::take_drop`이 커서 한 점으로 대상을 정하므로 그 점이 가려지면 안 된다.

### D8. 도크 열림 여부를 세션에서 걷어내는 방법 — 필드를 지운다
- **Options**: ⓐ `DockSession.panel` 필드 제거 ⓑ 필드는 두고 읽지 않음 ⓒ 필드는 두고 쓰지도 읽지도 않음(빈 문자열 고정)
- **Chosen**: ⓐ. 아무도 읽지 않는 값을 계속 적으면 다음 사람이 "복원되는 값"으로 오해한다. 옛 설정 파일에 남은 `"panel": "queue"`는 serde가 무시하므로(전제 4) 스키마 버전을 올릴 필요도 없다.
- **Source**: `src/app/settings.rs`에 `deny_unknown_fields` 없음 + 위키 `feat-session.md`의 「필드를 더할 때는 버전을 올리지 않는다」 계약(제거도 같은 이유로 안전하다).

### D9. 필터·열 폭은 그대로 복원한다
- **Options**: ⓐ 필터·열 폭은 종전대로 복원 ⓑ 도크 상태를 통째로 초기화
- **Chosen**: ⓐ. 요청은 "닫힌 채로 시작"이지 "설정을 잊으라"가 아니다. 열 폭은 FR-11이 별도로 요구한다.
- **Source**: 원문 요청 문면 + PRD FR-11.

### D10. 미리보기 수명 판정을 순수 함수로 뺀다
- **Options**: ⓐ `next_item` 순수 함수로 빼고 그것만 시험 ⓑ `PanelState`에 판정을 두고 `src/ui/panel/tests.rs`의 `draw_once` 하네스로 시험 ⓒ 판정을 패널에 두고 시험하지 않음
- **Chosen**: ⓐ. AGENTS가 「UI(HWND 필요) 로직은 테스트 비대상 — 순수 로직을 UI에서 분리해 테스트」로 못박은 그 형태다. ⓑ는 그 하네스에 끌기를 흉내 낼 통로가 없고(`src/ui/panel/tests.rs`에 `DragAndDrop` 사용 0건) 페이로드를 세우려면 하네스가 `Context`를 밖으로 내주도록 고쳐야 해 이번 범위 밖의 시험 기반 개조가 된다. ⓒ는 네 종료 경로 중 하나가 빠져도 아무 시험이 붉어지지 않는다.
- **Source**: `AGENTS.md` Conventions의 테스트 항목 · `src/ui/panel.rs:46`(`mod tests;` — 인라인 시험 없음) · `src/ui/panel/tests.rs:213`(`draw_once`).
